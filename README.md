echo "# Realtime AI Booking

AI-powered real-time booking system built with Next.js, Express, MongoDB, Socket.io, and LangChain (RAG).

## 🚀 Features
- 🔐 JWT Authentication (Register, Login)
- 📅 Booking CRUD (Create, List, Delete)
- ⚡ Real-time updates via Socket.io
- 🧠 AI Chat Assistant (LangChain + RAG)
- 🧑‍💼 Admin panel (confirm/cancel bookings)
- 🌐 Frontend: Next.js + RTK Query + TailwindCSS
- 🛠 Backend: Node.js + TypeScript + Express + MongoDB

## ▶️ Local Setup
```bash
git clone https://github.com/rahul-dev007/realtime-ai-booking.git
cd realtime-ai-booking
cd backend && npm install && npm run dev
cd ../frontend && npm install && npm run dev
